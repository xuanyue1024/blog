# 色彩调整说明

这份说明记录当前博客里浅色模式卡片的色彩设计，以及如果你想继续调“白一点”或“更有主题感”，应该改哪里、怎么改。

## 当前实现

卡片的基础背景来自 [src/styles/variables.styl](../src/styles/variables.styl) 里的 `--card-bg`，而公共卡片壳来自 [src/styles/main.css](../src/styles/main.css) 里的 `.card-base`。

当前浅色模式大致是这组值：

```stylus
--card-bg: oklch(0.992 0.008 var(--hue)) oklch(0.23 0.015 var(--hue))
```

这表示浅色模式的卡片不是纯白，而是“接近白、带一点主题色倾向”的底色。再叠加 `.card-base` 上很轻的边框和阴影后，卡片会比纯白更有层次。

## Oklch 三个参数分别是什么

`oklch(L C H)` 里三个参数分别是：

- `L`：亮度，范围大致是 `0` 到 `1`。越接近 `1` 越亮。
- `C`：色度，也可以理解成“颜色感”或“饱和感”。越接近 `0` 越接近灰/白。
- `H`：色相，决定偏向哪一种颜色家族，比如偏红、偏蓝、偏绿。这里用的是 `var(--hue)`，也就是站点主题色的色相。

所以 `oklch(0.992 0.008 var(--hue))` 的意思就是：

- 很亮
- 只有一点点颜色倾向
- 跟当前主题色保持一致

## 怎么调

### 1. 想更白

优先把 `C` 往下调，必要时再把 `L` 往上调：

```stylus
--card-bg: oklch(0.996 0.004 var(--hue))
```

如果你要完全纯白，可以直接用：

```stylus
--card-bg: #fff
```

或者：

```stylus
--card-bg: oklch(1 0 0)
```

### 2. 想更有主题感

把 `C` 调大一点，颜色会更明显，但也更容易显得“发色”：

```stylus
--card-bg: oklch(0.99 0.012 var(--hue))
```

如果还想再明显一点，可以继续加到 `0.015` 或 `0.02`，但建议小步调整。

### 3. 想卡片更“轻”一点

除了背景色，真正让卡片看起来“厚”的，往往是边框和阴影。当前公共卡片壳在 [src/styles/main.css](../src/styles/main.css) 里有这一层：

```css
.card-base {
    @apply rounded-[var(--radius-large)] overflow-hidden bg-[var(--card-bg)] transition border border-black/[0.03] dark:border-white/[0.08] shadow-[0_1px_1px_rgba(0,0,0,0.015)] dark:shadow-none;
}
```

如果你觉得卡片还是偏重，优先按这个顺序收：

1. 先把阴影继续减弱，甚至去掉。
2. 再把浅色边框透明度继续降一点。
3. 最后才考虑把 `--card-bg` 调得更接近白。

例如可以变成：

```css
@apply rounded-[var(--radius-large)] overflow-hidden bg-[var(--card-bg)] transition border border-black/[0.02] dark:border-white/[0.08] shadow-none dark:shadow-none;
```

### 4. 想让浮层也同步变轻

如果你改了卡片底色，通常也建议同步看一下 `--float-panel-bg`，不然卡片和浮层的视觉语气会不一致：

```stylus
--float-panel-bg: oklch(0.988 0.008 var(--hue)) oklch(0.19 0.015 var(--hue))
```

## 推荐调参范围

如果目标是“浅色模式更干净，但仍然不死白”，可以优先试这几个范围：

- `L = 0.99 ~ 1`
- `C = 0.003 ~ 0.01`
- `H = var(--hue)` 保持不变

一个比较稳的组合是：

```stylus
--card-bg: oklch(0.995 0.004 var(--hue))
```

如果你想做成几乎看不出颜色的白底，就继续把 `C` 降到接近 `0`。

## 经验建议

- 只改 `L`，通常会让卡片变亮，但颜色感不会明显变化。
- 只改 `C`，最适合控制“是不是还保留主题感”。
- 先动 `C`，再动 `L`，通常比反过来更容易找到舒服的观感。
- 如果你发现“白了但还是觉得重”，大概率不是背景色，而是边框和阴影在起作用。
